# Deadline Clock

A responsive circular year dial for tracking research conference deadlines.

**Live site:** https://deadline-clock.tangguo1999.chatgpt.site

## Features

- Live date and time hand
- Annual circular dial with month sections
- Conference deadline markers and connected labels
- Year switching across 2024–2027
- Countdown and past-deadline states
- Responsive desktop and mobile layout

The initial dataset was transcribed from the supplied reference image. Always verify submission dates against the official calls for papers.

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
